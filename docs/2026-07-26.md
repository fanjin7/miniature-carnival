#### 研究摘要

本研究探讨中国K-12计算机科学教师（CSTs）在教学实践中采纳生成式人工智能（GenAI）的情况，填补了学科教师如何参与新兴技术的理解空白。基于期望-价值理论（EVT），研究扩展了技术接受与使用统一理论（UTAUT），纳入创新期望（IE）、成本效益（CB）和感知风险（PR），从而捕捉动机驱动因素和潜在约束。采用混合方法设计：定量阶段，来自20个省份338名CSTs的调查数据通过结构方程模型（SEM）分析；定性阶段，12名CSTs参与概念地图支持的访谈，并进行主题分析。定量结果显示，绩效期望（PE）、努力期望（EE）和IE显著增强教师的使用态度（AU），而社会影响（SI）不显著；使用意向（IU）受IE、CB、AU和PR影响，PR负向影响；IU进一步显著预测行为使用意向（BI）。定性结果强调了感知的教师权威侵蚀、学生过度依赖、对GenAI功能的碎片化理解以及伦理数据安全担忧等障碍，同时指出了有针对性的专业发展和学科专用工具的重要性。研究结果表明，通过定制培训、分层支持资源和明确的伦理指南，学校和教育局可以促进教师有效使用GenAI。

#### 研究主要内容

本研究采用混合方法，基于扩展的UTAUT模型（加入创新期望、成本效益、感知风险），调查了中国K-12计算机科学教师对生成式人工智能（GenAI）在教学中的采纳情况。定量部分通过SEM分析338份调查数据，检验各因素对使用态度和行为意向的影响；定性部分通过主题分析12位教师的概念地图支持访谈，深入探讨采纳过程中的障碍与需求。

#### 研究论点

扩展UTAUT模型可以更全面地解释K-12计算机科学教师采纳GenAI的多维因素，强调除传统技术接受因素外，创新期望、成本效益和感知风险在教师决策中的关键作用，且专业发展与学科工具支持至关重要。

#### 研究摘要

虽然计算思维（CT）在K-12教育中日益重要，但教师通过文本编程教授CT仍然具有挑战性。为弥补这一空白，本研究提出并评估了一个自定进度的专业发展（PD）模块“Let's Code with GenAI”，旨在提升K-12教师的文本编程和CT教学能力。采用单组前后测设计，34名职前/在职教师于2025年完成了该模块，内容包括教学视频和基于Micro:bit与MakeCode (v11.3.22)的动手编程活动，并配备GenAI助手提供解释与调试支持。干预前后分别使用教师编程与计算思维信念量表（TBaCCT）以及编程/CT评估收集数据。后测在教学效能与价值信念（p < 0.001）、编程自我效能（p < 0.001）和CT自我效能（p = 0.015）上均显著高于前测；编程/CT评估得分也显著提高（p = 0.040）。自我效能与表现之间未发现统计学显著相关。总体而言，这些初步发现揭示了参与者在GenAI支持的自主PD模块后的自我效能、价值信念及编程/CT表现，同时也强调了未来需要对照研究的必要性。

#### 研究主要内容

本研究针对K-12教师在文本编程教学中面临的困难，设计和实施了一个由生成式AI（GenAI）支持的自定进度专业发展模块。通过前后测比较，发现该模块能显著提升教师的自我效能和价值信念，并对编程/CT表现有积极影响，但自我效能与表现之间的相关不显著。研究为AI辅助教师专业发展提供了初步证据。

#### 研究论点

生成式AI辅助的自定进度专业发展模块可能有效提升K-12教师的编程教学自我效能和价值信念，并对编程/CT表现产生积极影响，但其效果需要通过更严格的对照研究进一步验证。

#### 研究问题

生成式AI辅助的自定进度专业发展模块（“Let's Code with GenAI”）对K-12教师的自我效能、价值信念以及编程/计算思维表现有何影响？

#### 研究方法

研究类型：定量研究。样本与参与者：34名职前/在职K-12教师（摘要未说明具体人口学特征）。数据来源：前后测数据，包括教师编程与计算思维信念量表（TBaCCT）和一项编程/CT评估。分析方法：采用配对样本t检验（或非参数检验）比较前后测差异，并使用相关性分析（如Pearson相关）检验自我效能与表现之间的关系。研究设计为单组前后测设计，未设置对照组。

#### 主要发现

1. 在后测中，教师的教学效能与价值信念得分显著高于前测（p < 0.001）。
2. 编程自我效能（p < 0.001）和计算思维自我效能（p = 0.015）均显著提升。
3. 编程/CT评估成绩在后测中显著提高（p = 0.040），但自我效能与表现之间未发现统计学显著相关。

#### 对教师教育研究的启示

本研究展示了生成式AI在教师编程教育专业发展中的潜在应用，为设计自定进度的AI辅助培训模块提供了参考。研究设计采用单组前后测，提示未来研究需纳入对照组并考虑随机分配，以增强因果推断。同时，自我效能与表现不相关的发现表明，教师教育研究应同时关注认知和非认知因素，并采用多维评估工具。数据收集方法（量表和任务评估）和分析策略（前后测比较及相关性分析）可供后续类似主题研究借鉴。
