#### 研究摘要

目的：考察AI辅助、个体化运动管理模式对肥胖儿童身体成分、体能和姿势稳定性的影响，并为后续随机对照试验提供可行性基础。方法：单组前后测试点研究。19名单纯性肥胖儿童（7名女孩、12名男孩；平均年龄10.11±2.0岁）来自West China Second Hospital，于2024年7—9月完成12周运动干预。AI系统基于基线评估生成个体化FITT-VP处方，并通过训练反馈动态调整，由现场教练实施；干预前后测量结果。结果：19名儿童均完成干预，无不良事件。BMI由25.29±3.56降至23.64±3.60 kg/m²（p<0.001，d=0.46），体脂量由21.06±6.70降至17.94±6.69 kg（p<0.001，d=0.47）；腰围、握力、1分钟跳绳、1分钟仰卧起坐、坐位体前屈均显著改善。八方向姿势控制评估中，端点偏移和最大偏移在所有方向呈改善趋势，四个方向反应时间显著降低；感觉统合测试中SOT-4和SOT-5平均平衡百分比显著增加（p<0.01，d=1.05和d=0.58），综合平衡分增加24.15%（p<0.001，d=1.28），视觉比率增加19.5%（p<0.05，d=0.80），前庭比率增加15.3%（p=0.054，d=0.43）。结论：AI辅助、缺陷导向运动干预在该肥胖儿童队列中展示良好可行性与安全性；身体成分、运动功能和姿势控制指标的改善为儿童肥胖精准运动管理的后续确证性试验提供可行性依据。

#### 研究主要内容

该文评估AI辅助、缺陷导向的个体化运动管理模型在肥胖儿童中的可行性和初步效果。研究采用单组前后测试点设计，19名单纯性肥胖儿童完成12周干预。AI系统根据基线评估生成个体化FITT-VP运动处方，并依据训练反馈动态调整，由现场教练实施。干预前后测量身体成分、体能和姿势控制。结果显示所有参与者均完成干预且无不良事件；BMI、体脂量、腰围、握力、1分钟跳绳、1分钟仰卧起坐、坐位体前屈等指标改善；八方向姿势控制和感觉统合测试多个指标改善或呈改善趋势。结论强调该模式具有可行性和安全性，并为后续随机对照试验提供基础。

#### 研究论点

核心论点是：AI辅助、缺陷导向、个体化的运动管理在肥胖儿童中具有可行性和安全性，并伴随身体成分、运动功能和姿势控制方面的初步改善；但该研究为单组前后测试点，主要用于可行性验证，结论指向后续确证性试验，而非直接确证因果疗效。

研究类型：定量取向的单组前后测试点研究。样本/参与者：19名单纯性肥胖儿童（7名女孩、12名男孩；平均年龄10.11±2.0岁），来自West China Second Hospital，2024年7—9月完成12周运动干预。干预：AI系统基于基线评估生成个体化FITT-VP处方，并通过训练反馈动态调整，由现场教练实施。数据来源：干预前后测量，包括身体成分（BMI、体脂量）、体能（腰围、握力、1分钟跳绳、1分钟仰卧起坐、坐位体前屈）和姿势控制（八方向姿势控制、感觉统合测试SOT-4、SOT-5、综合平衡分、视觉比率、前庭比率）。分析方法：摘要未明确说明具体统计检验方法；结果报告p值和Cohen's d效应量，并报告部分百分比变化。

本文提出IslamicLegalBench，首个多学派伊斯兰法基准，用于评估LLM在广泛伊斯兰法学（fiqh）中的表现。基准从37部基础法律文本、跨越1200年、七个法学派中人工收集并组织718个评估实例，覆盖13项任务，并按复杂度分层，从基础回忆到法律理由识别（‘illah）、类比应用（qiyās）和跨学派综合。研究评估9个最先进LLM，发现显著局限：最佳模型仅达67.65%正确率和21.25%幻觉率；部分模型正确率低于35%，幻觉率超过55%。Few-shot提示无一致收益，模型分数变化为-3.64至+4.16分，收益集中在已较弱模型，说明封闭书本条件下提示无法弥补当前训练数据中伊斯兰法律知识不足。中等复杂度、需要精确逐字知识的任务错误率和幻觉率高，幻觉率最高达73%；高复杂度任务表现更好，可能因模型依赖语义泛化和冗长推理。虚假前提检测显示迎合风险：few-shot下9个模型中有5个接受误导假设的比例超过40%，最差为86.27%；few-shot使迎合性增加3.49个百分点。虚假前提接受率与总体表现呈强且显著负相关（Pearson r = –0.91, n = 9, p < 0.01）。结论是伊斯兰NLP的路径不在于轻量后处理如提示或指令调优，而在于丰富知识，优先用覆盖古典圣训集、主要伊斯兰法学派著作和法典汇编的大规模伊斯兰法律语料训练模型。

#### 研究主要内容

本文主题为伊斯兰法律领域的LLM基准评估，提出IslamicLegalBench，构建跨七个法学派、37部基础法律文本、1200年法律传统、718个实例和13项任务的评估集，并评估9个最先进LLM。研究关注模型在伊斯兰法知识回忆、法律理由识别、类比应用和跨学派综合中的正确率、幻觉率、few-shot提示效应及虚假前提迎合行为。摘要未显示该文属于学前教育、基础教育或教师教育主题，也未讨论教师数字素养、AI教学应用或教师培训中的AI整合。

#### 研究论点

论文主张：当前LLM在伊斯兰法律领域缺乏足够知识与精确推理能力，易产生幻觉和迎合性错误；few-shot提示或指令调优等轻量后处理不能补偿领域知识缺口，应优先通过大规模、多学派、跨时期的伊斯兰法律语料来丰富模型知识。

核心问题是：LLM能否可靠地推理伊斯兰法？具体评估其跨多学派伊斯兰法知识与推理表现、不同复杂度任务上的表现、few-shot提示是否带来收益，以及模型在虚假前提和迎合行为上的风险。更细的正式研究问题摘要未说明。

#### 研究方法

研究类型：以基准测试为基础的定量计算评估，非传统调查或干预实验。样本或参与者：9个最先进LLM；评估数据集包括718个实例、13项任务，来自37部基础法律文本、七个法学派、跨越1200年。数据来源：37部基础伊斯兰法律文本，由研究者人工收集并组织，按任务复杂度分层。分析方法：模型基准测试；计算正确率与幻觉率；比较few-shot prompting前后变化；检测虚假前提接受率和迎合行为；使用Pearson相关分析虚假前提接受率与总体表现关系（r = –0.91, n = 9, p < 0.01）。具体模型版本、数据划分、标注者一致性、提示细节和额外统计检验摘要未说明。

#### 研究摘要

本研究考察基于先前知识的教学对尼日利亚Niger State高中学生批判性与评价性阅读理解表现的影响。研究指出，第二语言学习者在较高认知层次的阅读理解中持续面临困难，原因包括教学策略不足以及学生已有知识框架未被充分激活。研究采用准实验前测—后测非随机控制组设计，通过多阶段抽样从Bida地方政府区两所公立学校选取120名高中（senior secondary）学生；实验组60人接受基于先前知识激活技术的教学，控制组60人接受常规教学。数据由经过验证的阅读理解篇章收集，用于评估字面、推断、批判和评价理解水平，工具信度为0.85（Kendall和谐系数）。数据分析采用描述统计（均值和标准差）和推断统计（t检验），显著性水平为0.05。结果显示，两组前测平均分接近（实验组1.9，控制组1.8），但实验组后测平均分（2.3）显著高于控制组（2.1），t计算值（3.92）大于t临界值（1.96）。研究结论认为，先验知识激活能通过帮助学生更有效地分析、解释和评价文本信息，显著提升其批判性评价阅读理解；建议开展相关教师培训、将图式化阅读教学纳入课程并组织持续专业发展工作坊。

#### 研究主要内容

论文聚焦尼日利亚高中二语阅读教学中的高阶阅读理解问题。研究背景是学生在批判性和评价性阅读理解上表现不足，部分原因在于教学策略不够有效，且未能激活学生已有知识框架。研究目的为检验基于先前知识的教学是否比常规方法更能提升学生的批判性与评价性阅读理解表现。研究采用准实验前测—后测非随机控制组设计，样本为Bida地方政府区两所公立学校的120名高中学生，实验组与控制组各60人。实验组接受先前知识激活技术教学，控制组接受常规教学。数据来自经过验证的阅读理解篇章，覆盖字面、推断、批判和评价理解层级，信度为0.85（Kendall和谐系数）。分析使用均值、标准差和t检验，显著性水平0.05。结果显示实验组后测表现显著优于控制组，说明先验知识激活对高阶阅读理解有积极影响。论文据此强调图式激活在阅读教学中的重要性，并指出教师在创新教学策略方面的专业知识缺口，建议加强教师培训、课程整合和持续专业发展。

#### 研究论点

论文的核心论点是：基于先前知识激活的教学能够显著提升学生在批判性和评价性层面的阅读理解表现，尤其有助于第二语言学习者分析、解释和评价文本信息；因此，图式激活应成为阅读教学的重要策略，而教师教育需弥补教师在创新教学策略方面的专业知识缺口。
