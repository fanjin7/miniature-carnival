#### 研究摘要

该研究关注生成式人工智能（GenAI）在职前教师备课中的应用风险：GenAI往往在职前教师尚未厘清教学设计理据之前，就直接给出完整教案，从而容易诱发自动化偏差与认知卸载。作者采用多案例研究设计，考察中国5名职前数学教师在使用GenAI备课过程中如何协商“认知权威”。5个案例由42名职前教师经初步量化筛查后选出。研究整合屏幕录制生成的事件日志、同时性言语报告（出声思维）、视频刺激回忆访谈与书面反思，构建了包含34个决策事件的证据矩阵；依据“提议来源—参与者行动—所援引的理据（warrant）—该理据是否在教案中落实”四者关系，将权威判定为保留、共享或让渡。结果显示：权威保留16个事件、共享12个事件、让渡6个事件，且存在个案间差异；外显行为与权威位置并非固定对应，专业理据有时未被落实。研究识别出两类脆弱性：一是“闭环验证”，即参与者已意识到AI输出的不确定性，却仍请同一个AI来验证（共2个案例的4个事件）；二是“洞察—行动落差”，即已识别的教学问题未被转化为教师的教学应对计划（单一案例的3个事件）。结论认为，AI辅助备课的教育价值更多取决于任务是否要求独立验证、以及决策是否有理据且被真正落实，而不取决于新手对AI输出做了多少修改。学段信息摘要未说明（对象为职前数学教师）。

#### 研究主要内容

论文聚焦“AI辅助备课中的认知权威协商”这一主题。作者指出，GenAI能在职前教师阐明教学推理之前就生成完整教案，其结果是职前教师可能把本应由自己承担的判断权交给AI（认知卸载与自动化偏差）。为刻画这一过程，研究没有停留在“改了多少AI文本”这类行为指标上，而是引入论证理论中的“理据（warrant）”概念，把权威视为一种在具体决策事件中被协商、被援引并被检验的关系性状态。研究以中国5名职前数学教师为案例，数据来源包括屏幕录制事件日志、同时性言语报告、视频刺激回忆访谈与书面反思，最终整理为34个决策事件的证据矩阵。分析按事件逐一判定权威归属（保留/共享/让渡），并检验所援引的专业理据是否真正落实到教案。研究发现权威分布以“保留”和“共享”为主，但个案差异明显；外显的编辑行为并不稳定地对应权威状态，参与者有时口头援引了专业理据却未在教案中落实。两类风险机制尤为值得关注：其一为“闭环验证”，即用同一个AI验证其自身输出的可靠性，形成自我确认的封闭回路；其二为“洞察—行动落差”，即教师已识别教学问题却没有转化为可执行的教师回应方案。研究据此主张，教师教育中的AI整合应通过任务设计强制要求独立验证与理据落实，而非仅训练“修改提示词或修改输出”的技能。

#### 研究论点

作者的核心论点（proposition）是：AI辅助备课的教育价值，关键不在新手对AI输出做了多少编辑，而在任务是否要求学习者进行独立验证，以及其决策是否有理据支撑并真正落实到教案之中。换言之，认知权威的“保留与共享”质量而非“修改频率”才是判断GenAI教学价值的核心标准。

#### 研究问题

摘要未以疑问句形式明确列出研究问题；据摘要可推断其探究的核心问题是：职前数学教师在使用GenAI进行教学设计时，如何协商与AI之间的认知权威（权威被保留、共享还是让渡）？其援引的专业理据是否在教案中得到落实？在此过程中出现了哪些脆弱性模式？

#### 研究方法

研究类型：质性研究为主的多案例研究（multiple-case study），并在案例筛选阶段嵌入初步量化筛查，整体可视为“量化筛查＋质性多案例”的混合抽样设计。样本/参与者：中国5名职前数学教师作为案例；案例从42名职前教师中通过初步量化筛查选出。数据来源：①屏幕录制生成的事件日志（screen-recording-derived event logs）；②同时性言语报告（concurrent verbalizations，出声思维）；③视频刺激回忆访谈（video-stimulated recall interviews）；④书面反思（written reflections）。数据组织形式：四类数据整合为“证据矩阵”，共34个决策事件（decision episodes）。分析方法：以决策事件为分析单位，依据“提议来源—参与者行动—所援引理据—理据是否在教案中落实”四要素关系进行编码，将权威判定为保留（retained）、共享（shared）、让渡（ceded）；并对反复出现的脆弱性模式作跨案例比较（如闭环验证出现于2个案例4个事件，洞察—行动落差出现于1个案例3个事件）。信效度与编码一致性程序：摘要未说明。

#### 主要发现

1. 权威分布与个案差异：34个决策事件中，认知权威被“保留”16个事件、“共享”12个事件、“让渡”6个事件，且不同案例之间存在明显差异，说明职前教师与GenAI的权威关系并非单一模式。2. 行为与权威错位、理据落实不足：外显操作行为（如修改AI输出）与权威位置之间不存在固定对应关系；参与者有时援引了专业理据，但该理据并未在最终教案中被真正落实，即“说了理据”不等于“用了理据”。3. 两类脆弱性机制：一是“闭环验证”（2个案例共4个事件），参与者已察觉AI输出的不确定性，却仍请求同一个AI来验证该输出，形成自我确认的封闭回路；二是“洞察—行动落差”（1个案例共3个事件），参与者识别出了教学问题，但没有转化为具体的教师回应与教学计划。

#### 对教师教育研究的启示

对教师教育研究的启示：（1）前沿主题上，可把“认知权威”“理据（warrant）”“独立验证”“认知卸载/自动化偏差”作为GenAI与教师教育交叉研究的新分析切口，从“教师会不会用AI”转向“教师是否对AI保持认知主导权”。（2）研究设计上，本文示范了“量化筛查＋目的性抽样”的多案例策略（42人中选5人），以及“决策事件”作为分析单位的中层粒度设计，既保留质性深度又使跨案例比较可操作，可作为AI辅助备课、教师智能素养研究的可复制设计模板。（3）数据收集上，屏幕录制事件日志＋同时性言语报告＋视频刺激回忆访谈＋书面反思的四源三角互证，能同时捕捉外显操作、即时认知与回溯性理据表述，弥补单靠访谈或问卷难以揭示“行为—理据—落实”链条的不足；对“洞察—行动落差”这类现象尤为必要。（4）分析方法上，可按“提议来源—行动—援引理据—理据是否落实”的四要素编码框架来判定权威归属，并注意避免以修改次数等行为指标替代认知层面判断；同时可借鉴其识别“风险模式”（闭环验证、洞察—行动落差）的跨案例比较思路。（5）对教师培养实践的启示可延伸为任务设计研究：设计必须强制独立验证、必须书面说明理据并检验其落实的备课任务，并开展干预研究检验其对职前教师认知权威的影响。（6）研究局限与空白：学段（学前/小学/初中）与具体数学主题摘要未说明，样本仅5名中国职前数学教师、单国别情境，编码信度与研究者立场等程序信息摘要未说明，提示后续可做多学段、多学科、更大样本及干预类研究。

#### 研究摘要

本文提出ephegogy理论，旨在弥合传统教育模式与人工智能增强社会中青少年发展需求之间的差距，并融合建构主义、连通主义与生成主义，探讨生成式人工智能（GenAI）与主动学习如何支架青少年的动机、自主性与相关性。研究采用混合方法案例研究，在2024—2025年单一中学地理课程中实施。定量数据来自匹配的前后测调查，测量动机与自我效能（N = 17；自我效能复合指标N = 11）以及控制点（N = 12），并使用适配14岁以下、以英语为附加语言为主群体的工具；另有匹配的投入调查（N = 24）和课程结束共创调查（N = 33）。定性数据包括74名学生的个人反思，基于文化历史活动理论（CHAT）框架进行主题分析，并分析74名学生的开放文本调查回答。研究发现具有关联性和探索性：复合动机显著提高（p = 0.043, d = 0.53），其中学校享受感显著上升（p = 0.028）；在另一工具上，使用AI工具的信心出现最大单项提升（p = 0.016），相对于传统课程的动机也上升（p = 0.040），但因检验多个题项，这些结果被视为探索性。自我效能与控制点未显示可靠变化。质性主题以选择、学习契约和资源自主为主；多数学生披露并反思了其AI使用，典型学生体验是矛盾的，既重视自主性又觉得要求较高。作为单一试点案例，样本小、匹配样本、无控制组且由单一教师研究者担任唯一编码者，结论具有情境性，不能支持因果推断。

#### 研究主要内容

论文提出ephegogy这一理论框架，将青少年教育视为AI时代一个需要独立框架的发展阶段，并通过逐步沉浸和“作者声音”评估来操作化。研究在单一中学地理课程中开展2024—2025年的混合方法试点，融合自我决定理论、ephegogy和CHAT三个框架。干预整合生成式AI与主动学习，关注动机、自主性和相关性。定量部分使用匹配前后测调查、投入调查和课程结束共创调查；定性部分分析74名学生的个人反思和开放文本回答，采用CHAT框架进行主题分析。结果显示复合动机和学校享受感显著提高，AI工具使用信心和相对于传统课程的动机也有提升，但自我效能和控制点无可靠变化；质性上，选择、学习契约、资源自主是主导主题，学生体验总体矛盾。作者强调这是探索性试点，不能作因果结论，并提出SAV量规等工具用于支持元认知反思和负责任的共创，评估学生作者声音而非依赖AI检测。

#### 研究论点

核心论点是：传统教育模式难以回应AI增强社会中青少年的发展需求，ephegogy可作为面向青少年阶段的独立教育框架；通过整合生成式AI与主动学习，并以选择、学习契约、资源自主和“作者声音”评估为支架，可提升青少年学习动机、自主性与相关性；但这一主张目前仅得到单一课堂试点的初步、关联性证据支持，尚不能作因果推断。

#### 研究摘要

本研究旨在将Chiu等（2025）开发的“教师人工智能能力自我效能感量表”（TAICS）改编为土耳其语，并在土耳其教育情境中检验其心理测量学属性。研究属于方法学取向的量表改编与效度验证研究，改编流程包括正向翻译、翻译审查、回译、语言润色、专家评估、预测试与正式验证分析，先后有五个研究小组参与（领域专家、语言专家、职前英语教师、预测试参与者，以及来自不同学段与学科的教师）。正式验证样本为449名教师。验证性因素分析支持原量表的六因子结构（AI知识、AI教学法、AI评价、AI伦理、以人为本的教育、专业参与）；二阶验证性因素分析进一步表明，这些维度可归属于“教师AI能力自我效能感信念”这一高阶构念。信度分析显示，各分量表与总分的Cronbach's α、McDonald's ω与组合信度系数均达到可接受水平；聚合效度得到支持，但区分效度结果显示部分理论相关维度之间存在较明显的实证重叠。测量等值性分析支持该量表在性别间的可比性。总体而言，土耳其语版TAICS量表提供了心理测量学证据，支持其在土耳其用于评估教师的人工智能能力自我效能感信念。

#### 研究主要内容
